# Image Resize

React приложение с интерфейс за преоразмеряване на снимки от папката `images/` и запис в `resizeimages/`.

## Изисквания

- [Node.js](https://nodejs.org/) 18 или по-нова версия
- npm (идва с Node.js)

## Инсталация

1. Отвори терминал в папката на проекта.
2. Инсталирай зависимостите:

```bash
npm install
```

## Стартиране

Стартирай API сървъра и React интерфейса с една команда:

```bash
npm start
```

- Frontend: **http://localhost:5173**
- API: **http://localhost:3001**

Ако API или frontend вече са пуснати, `npm start` ще използва текущите процеси вместо да спира заради зает порт.

### Отделно (по избор)

```bash
# Само API сървър
npm run server

# Само React интерфейс
npm run dev
```

## Как се ползва

1. Сложи снимките, които искаш да преоразмериш, в папката `images/`.
2. Отвори приложението в браузъра.
3. Избери снимки от списъка (или натисни **Избери всички**).
4. Задай **ширина**, **височина** и **fit** режим.
5. Натисни **Resize**.
6. Резултатът се записва в `resizeimages/` и се показва в секция **Резултат**.

Ако добавиш нови файлове в `images/`, натисни **Презареди**.

## Папки

| Папка | Описание |
|-------|----------|
| `images/` | Оригинални снимки за обработка |
| `Downloads/resize-ГГГГ-ММ-ДД/` | Преоразмерени снимки (Windows Downloads, папка по дата) |
| `src/` | React frontend код |

## Други команди

```bash

npm run server:watch

# Production build на frontend
npm run build

# Преглед на production build

```

## Тема

В горния десен ъгъл има тогъл за **светла** и **тъмна** тема. Изборът се запазва автоматично в браузъра.

## Поддържани формати

`.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.avif`, `.tiff`
